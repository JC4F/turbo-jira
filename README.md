# Build a Jira clone apps

Techstack:

- 🎇 Monorepo with Turborepo
- 🎊 Deploy: Vercel, Render
- ↩️ FE: Vue3, Vue Shadcn, Tailwind, Pinia, Apollo
- 🎆 BE: NestJs, GraphQL, Apollo, Typeorm, PostgreSQL

### Install packages

```shell
pnpm i
```

### Setup .env file

Change .env.example => .env

### Start the app

```shell
pnpm dev
or
pnpm start
```
